# Cargo Pad Bonus Research: Updated

Adds repeatable research that increases the number of cargo landing pads allowed on a surface. Each level adds one pad; its cost grows with the research level.

This continuation uses the Factorio 2.1 cargo-pad-count technology effect while retaining the original research identity, science requirements and progression.

Requires Factorio 2.1.24 or newer. Requires Space Age and the planetary science packs listed by the technology. The research changes the pad allowance; it does not place or connect pads.
